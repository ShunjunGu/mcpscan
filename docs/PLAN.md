## 每日固定动作

- 至少 3 个有意义的 commit（禁止空提交/机械拆分）。

## 风险与削减顺序

若进度落后，按下列顺序削减，**不削减**归一化层、TP001–TP005、SARIF、基线：

1. 砍 stdio 连接模式（D11）→ 只保留快照与配置两种输入。
2. 砍 TP011/TP013/TP017/TP020（低可检性类别）→ 在报告头部声明。
3. 砍 Markdown 报告格式 → 保留 text/JSON/SARIF。
4. 砍 CLI 配置合并 → 只支持命令行参数。
